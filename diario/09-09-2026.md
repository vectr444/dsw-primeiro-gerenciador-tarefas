# Aula 01 — Evoluindo a Segurança do Nosso Servidor (09/09/2026)

## ✅ O que eu aprendi

Eu já conhecia sobre injeções sql, mas não sabia como exatamente eram feitas, nem como proteger o código desses tipos de ataques. 

Então apliquei o conteúdo do Guia, implementando as 4 partes fundamentais:
- Tipagem explícita: Criação da interface "Tarefa" e tipagem de retornos.
- Validação centralizada: Uso de constantes e funções helpers para não ficar repetindo código.
- Prepared Statements: Compilação prévia das querys no SQLite para ganhar performance e evitar SQL Injection.
- Erros controlados: Tratamento de erros nas rotas para não vazar a estrutura do banco de dados, e também para evitar quebras quando enviam arrays na URL.

Também incluí os testes no "resquests.http" para validar a blindagem das requisições GET.

## 🧩 Principal dificuldade
Após aplicar o código, o editor código começou a acusar erros no arquivo server.ts, dizendo que não conseguia encontrar os tipos de dependências como node ou express. Fora isso, seguind o guia, a implementação foi tranquila

## 🔧 Como eu resolvi
Percebi que a pasta node modules não existia no diretório do projeto. Então rodei o comando "npm install" no terminal para que as dependências fossem instaladas. (deixei de usar o codespaces para usar o visual studio, por isso estava sem o node modules)
